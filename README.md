# eCommerce Analytics Dashboard

This project analyzes eCommerce performance data from 2024 using Power BI.

## Files

- `ecommerce_2024.csv`: Raw transactional and customer data.
- `ecommerce_2024.pbix`: Power BI report with dashboards and visualizations.

## Key Insights

- Sales trends and revenue breakdown
- Customer segmentation and behavior
- Product performance analysis

## How to Use

1. Open `ecommerce_2024.pbix` in Power BI Desktop.
2. Refresh data if needed using the CSV file.
3. Explore the interactive dashboard.
